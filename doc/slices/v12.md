# VS-12 — SEO, Analytics & Social Sharing

## 1. Goal

Build a complete SEO, analytics, and social-sharing module so the photography website can:

* Rank better in search engines

* Display professional previews when shared on social media

* Track visitor activity

* Measure portfolio engagement

* Help photographers understand which projects attract visitors

* Configure SEO without editing code

This slice makes the website more professional and valuable as a sellable product.

# 2. Scope

VS-12 includes:

1. Global SEO configuration

2. Page-specific SEO

3. Project-specific SEO

4. Open Graph metadata

5. Twitter/X card metadata

6. Sitemap generation

7. Robots configuration

8. Structured data

9. Analytics integration

10. Privacy-friendly tracking settings

11. Social sharing buttons

12. SEO preview

13. Analytics dashboard

# 6. SEO Title Rules

Recommended title length:

```
30–60 characters
```

Display a live counter:

```
SEO Title
[Frame & Soul Photography | Mumbai Photographer]

Characters: 48
Status: Good
```

Warning states:

```
Too short
Recommended
Too long
```

The system should not block saving only because a title is slightly outside the recommended length.

# 7. Meta Description Rules

Recommended length:

```
120–160 characters
```

Show:

```
Characters: 143
```

The description should:

* Clearly explain the page

* Include relevant photography keywords naturally

* Avoid keyword stuffing

* Be unique for important pages

* Include a call to action when appropriate

# 13. Canonical URLs

Every indexable page should have one canonical URL.

Examples:

```
https://example.com/
https://example.com/portfolio
https://example.com/about
https://example.com/contact
https://example.com/projects/riya-arjun-wedding
```

Rules:

* Use absolute URLs

* Avoid duplicate canonical URLs

* Normalize trailing slashes consistently

* Do not expose internal admin routes

* Do not generate canonical URLs for unpublished projects

# 14. Sitemap

```
/sitemap.xml
```

Include:

* Homepage

* Portfolio page

* About page

* Services page

* Contact page

* Published and indexable projects

Exclude:

* Admin pages

* Draft projects

* Hidden projects

* Deleted projects

* Private client galleries

* Maintenance pages

### Suggested endpoint

http

```
GET /sitemap.xml
```

The sitemap should be generated dynamically from published content.

# 27. Validation

### Tracking ID

Validate according to the selected provider.

### Canonical URL

Must be an absolute HTTPS URL in production.

### SEO title

Required for global settings.

### Meta description

Required for global settings.

### OG image

Must reference an existing media record.

### Analytics event

Only allow predefined event names.

### Project SEO

Only allow SEO editing for existing projects.

# 28. Edge Cases

### No OG image

Use the default OG image.

### No project-specific SEO

Use global SEO fallback.

### Project unpublished

Do not include it in sitemap.

### Analytics disabled

Do not load analytics scripts or record events.

### Invalid tracking ID

Show configuration error without breaking the website.

### Missing canonical URL

Use the configured site URL and route path.

### No analytics data

Show an empty state rather than fake numbers.

### Social sharing unsupported

Use copy-link fallback.

### Maintenance mode

Prevent indexing of maintenance content.

# 29. Security Requirements

* Protect all admin SEO and analytics routes.

* Sanitize metadata fields.

* Prevent script injection in title and description fields.

* Never allow arbitrary scripts through normal settings.

* Do not expose analytics provider credentials.

* Validate analytics events server-side.

* Do not expose private enquiry information.

* Do not include admin routes in sitemap.

* Restrict analytics queries to authenticated admins.

# 32. UAT Acceptance Criteria

VS-12 is accepted when:

* Admin can manage global SEO settings.

* Admin can manage page-specific SEO.

* Admin can manage project-specific SEO.

* Search and social previews update correctly.

* Sitemap includes only published and indexable content.

* Robots file excludes admin and API routes.

* Structured data is generated correctly.

* Analytics can be enabled or disabled.

* Analytics events are validated.

* Analytics dashboard displays real available data.

* Project sharing works on desktop and mobile.

* Private data is never included in metadata or analytics.

* SEO settings do not require code changes.

* Existing portfolio, About, Contact, and Settings modules continue working.
