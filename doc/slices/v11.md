# VS-11 — Site Settings, Branding & Global Content Management

## 1. Goal

Build a centralized **Site Settings & Branding module** that allows the photographer/admin to manage all global website information from one place.

The photographer should be able to change:

* Website name
* Logo
* Favicon
* Photographer name
* Tagline
* Primary contact details
* Social media links
* Navigation menu
* Footer content
* Copyright text
* Global CTA text
* Default SEO information
* Open Graph/social sharing information
* Business/photographer location
* Website visibility settings

### Business Objective

The website should feel like a **real product that can be sold to different photographers**, rather than a website hard-coded for one photographer.

The ideal architecture becomes:

```text
ADMIN
 │
 ├── Branding
 ├── Contact Information
 ├── Navigation
 ├── Footer
 ├── Social Links
 ├── SEO
 └── Global Settings
          │
          ▼
     PUBLIC WEBSITE
          │
          ├── Header
          ├── Logo
          ├── Navigation
          ├── CTA
          ├── Footer
          ├── SEO
          └── Social Links
```

---

# 2. Roles

### Admin

Full access:

* View settings
* Edit settings
* Upload logo
* Upload favicon
* Manage navigation
* Manage social links
* Manage footer
* Manage SEO
* Publish changes
* Preview changes

### Public Visitor

Can only see published settings.

# 8. Navigation Management

`navigation_items` table:
- id (UUID)
- label (VARCHAR)
- url (VARCHAR)
- type (INTERNAL, EXTERNAL, ANCHOR)
- sort_order (INTEGER)
- is_visible (BOOLEAN)
- open_new_tab (BOOLEAN)

---

# 9. Social Media Management

`social_links` table:
- id (UUID)
- platform (VARCHAR)
- label (VARCHAR)
- url (TEXT)
- icon (VARCHAR)
- sort_order (INTEGER)
- is_visible (BOOLEAN)

# 10. Footer Management
