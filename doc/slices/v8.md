# VS-08 — Public Portfolio / Project Showcase

**Project:** Photography Showcase Website
**Vertical Slice:** VS-08
**Module:** Public Portfolio / Project Showcase
**Depends on:** VS-04 Category Management, VS-05 Photo Management, VS-06 Project/Gallery Management, VS-07 Homepage Content Management

---

## 1. Slice Goal

Build the complete public-facing **Portfolio experience** where visitors can:

* Browse photography categories
* Browse projects
* View project covers
* Open a project
* Experience its photography story
* View photos in a premium gallery
* Open photos in fullscreen/lightbox
* Navigate between photos
* See project information
* Filter projects by category
* Share a project
* Navigate to Contact Photographer

The experience should feel like a **premium photography portfolio**, not a generic CRUD gallery.

### Core visitor journey

```text
Homepage
   ↓
Explore My Work
   ↓
Portfolio
   ↓
Category
   ↓
Project
   ↓
Beautiful Gallery
   ↓
Photo Lightbox
   ↓
Contact Photographer
```

# 28. Public API Security

Public APIs should **never return admin-only information**.

Do not expose:

```text
created_by
internal_notes
admin_metadata
storage_private_keys
draft_content
```

Return only visitor-required information.

# 30. Photo Visibility
